## MoSCoW Prioritisation

### Must Have (MVP Polish — Before User Test)

- **Weekly Goals unit tests** — Mirror the `GeneralGoalsPresenter.test.tsx` pattern. Cover the state hook (add/remove/toggle/edit goals, reflection completion gating, dirty tracking), the presenter (edit vs view mode, submit flow, empty state), and the sub-components that have conditional UI (MomentCard collapse-on-untick, WeekRail tap-anchored bloom).
- **Seed a Reading module into the Depression program** — Sessions 1-3 psychoeducation. One BE seed entry + publish.

### Should Have (Depression Sessions 4-6 — Cognitive Phase)

- **Thinking Traps** — Psychoeducation gateway into the cognitive toolkit. Read/reflect pattern, closest in complexity to Reading.
- **Thought Monitoring** — Log unhelpful thoughts with optional thinking-trap tagging. Awareness before challenging.
- **Thought Challenging** — Structured evidence worksheet. Core CBT cognitive restructuring technique.

### Could Have (Depression Sessions 6-8 — Advanced)

- **Longitudinal Model** — Beck formulation narrative. High clinical value, lower frequency.
- **Belief Change Evidence Table** — Two-column for/against evidence across multiple beliefs.
- **Modifying Unhelpful Beliefs** — Belief modification worksheet.

### Won't Have (This Cycle)

- **Additional programs** (GAD, Panic, OCD, Health Anxiety, Phobias, PTSD, Agoraphobia, Social Anxiety) — Depression must prove the model first.
- **Self-help program recommendations** — Post-MVP.
- **PWP differentiation** — Falls out of the CBT toolset once the behavioural phase is complete.
- **Admin content authoring UI** — Seeds suffice for MVP.
- **Messaging/chat** — Assignment notes cover therapist-patient communication.
- **Data export / reporting** — Not blocking the homework loop.
- **Auto-generated recurring weekly assignments** — Therapists assign manually; recurrence fields exist server-side but auto-creation is post-MVP.
- **Refactor of duplicated test mocks** — Cleanup task, not user-facing.

## Recommendation

### 1. Close the two polish items. One PR each, both small.

**PR A — Weekly Goals tests.** Use `GeneralGoalsPresenter.test.tsx` + `useGeneralGoalsState.test.ts` as the pattern reference. The `test-utils/presenterMocks.ts` factory is already set up. Target: state hook + presenter + MomentCard (the largest sub-component). WeekRail and CoachMessage can be covered by presenter-level tests. This is the only MVP code without coverage.

**PR B — Reading in Depression seed.** Add an entry to the Depression program's `programModules` in `seedAll.ts` pointing to a foundational depression psychoeducation reading module. Publish. Run `npm run update-types` on FE (no type changes expected, just a seed run).

Both should land before the real user test — not as a quality checkbox, but because a therapist running the MVP flow will notice the missing reading module immediately, and because Weekly Goals is the highest-interaction surface in the app and the most likely to hide a bug.

### 2. Run the real user test. Stop building features until feedback lands.

The last five briefs promised this moment. Put the app in front of one of the business-partner therapists and have them:
- Assign a week-1 program to a test patient account
- Complete PHQ-9, Activity Diary, Five Areas, General Goals, Weekly Goals, and a reading module as the patient
- Review the results as the therapist
- Assign Weekly Goals again for week 2, tick goals off, reflect, submit
- Repeat as session 3

What the test produces: a specific, prioritised list of gaps that will reshape the cognitive phase scope. **Do not start Thinking Traps without this feedback.** Building tier-2 tools blind to real therapist reaction is exactly the scope creep this PM brief exists to prevent.

### 3. After feedback: Thinking Traps as the cognitive-phase opener.

Simplest of the cognitive tools, closest in pattern to Reading. Natural re-entry point after the user test, assuming feedback doesn't redirect priorities. Defer scope decisions on Thought Monitoring and Thought Challenging until Thinking Traps is in real hands too.
